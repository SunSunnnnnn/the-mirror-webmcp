# SunSun Design Judgment Dataset — Public Sample

An anonymized demonstration subset derived from real SunSun design cases.

The sample contains four structured cases, eight public judgment rules, the remote uncertainty boundary, a small concern vocabulary, and the contracts needed by The Mirror's four WebMCP tools. It contains no client media.

The cases demonstrate four recurring judgment themes:

1. underlying need over literal request;
2. constraints as design material;
3. identity and designed visibility;
4. long-term evolution and previous work as material.

The complete proprietary SunSun Design Knowledge Layer is not included in this repository.
